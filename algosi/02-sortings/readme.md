# Лабораторная работа по сортировкам

Здесь в одном бинарнике содержатся первая и вторая лабораторные работы.

## Сборка

### CMake

1. Сгенерировать скрипты сборки с помощью

```cpp
cmake -B build
```

2. Собрать проект командой

```sh
cmake --build build --parallel
```

Чтобы не утруждать себя написанием одних и тех же команд, можно воспользоваться
приложенным скриптом build.sh:

```sh
./build.sh rebuild # перегенерирует скрипты сборки и собирает проект
./build.sh # собирает проект, не перегенерируя скрипты сборки
```

### Make

Просто и лаконично:

```sh
make
```

Чтобы прибрать за собой, всегда можно запустить

```sh
make clean
```

## Запуск

```sh
bin/sortings <сортировка>
```
