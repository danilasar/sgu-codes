# Фреймворк для СДиА

Решает декларативно описанные алгоритмические задачи из toml-сценариев.
Предназначен для сдачи лабораторных работ по структурам данных и алгоритмам,
может быть использован как стенд для демонстрации работы различных алгоритмов.

## Программа

### Зависимости

Работоспособность проверена со следующими инструментами:

+ GNU GCC 14.2.1
+ CMake 4.0.1

Зависимости:

+ toml++ 3.4.0 — формат конфигурационных файлов, используется для написания тестов
+ Lua 5.4.7 — скриптовый язык, используется для написания тестов
+ sol2 3.5.0 — обёртка над Lua API

### Сборка

1. Сгенерировать скрипты сборки с помощью

```cpp
cmake -B build
```

2. Собрать проект командой

```sh
cmake --build build --parallel
```

Чтобы не утруждать себя написанием одних и тех же команд, можно воспользоваться
приложенным скриптом build.sh:

```sh
./build.sh rebuild # перегенерирует скрипты сборки и собирает проект
./build.sh # собирает проект, не перегенерируя скрипты сборки
```

### Запуск

```sh
bin/sortings <сценарий.toml> [задача]
```

Если задача не указана, поочердёно выполняются все имеющиеся в файле.

## Сценарии

### Сценарный язык

Для описания сценариев используется формат toml. Основную его часть представляет
группа таблиц tasks, в которой содержатся описания поставленных задач. По
умолчанию выполняются все задачи из файла, но при желании пользователь может
задать конкретный список.

Задача, как правило, имеет следующий вид:

```toml
[tasks.task_name] # task_name - название задачи
algorithm = "quick_sort" # название одного из поддерживаемых фреймворком алгоритмов
debug = true # генерировать ли отладочную информацию (трассировки и пр.)
timer = true # измерять ли длительность выполнения задачи
#  и произвольные ключи, специфичные для конкретного алгоритма - входные данные и пр.
```

### Заготовки

В репозитории можно найти несколько готовых сценариев — как минимум один для
каждого поддерживаемого алгоритма. Если документация противоречит содержимому
заготовки, скорее всего следует полагаться на содержимое загоотвки.
